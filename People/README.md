# People

Your personal CRM: one Markdown file per person (`firstname-lastname.md`).

Each file can hold: who they are, how and when you met, what connects you, which of your projects they relate to, open promises in both directions, and a dated log of interactions. Facts carry their source (e.g., "from email, 2026-10-12").

People connect almost every part of a second brain, so flows (meetings, email, events) often propose updates here. Template: `_guide/templates/person.md`.

Many contacts but only a few that matter? An option is a single `contacts.csv` table for everyone plus full files only for the important people: see `_guide/library/patterns/contacts-table.md`.
