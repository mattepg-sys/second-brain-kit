# Patterns (optional)

Ways of organizing a second brain that worked for real people. They are **options to offer when they fit**, never defaults to impose. Mention a pattern only when the person's situation matches its "Fits when" line.

| Pattern | Fits when | File |
|---|---|---|
| Project chats + a horizontal layer | The person already works in one AI chat or project per topic, each with its own folder, and loses the overview | `project-chats.md` |
| Improvement folder | The person has ideas about the brain itself while using it, and wants them collected without derailing work | `improvement-folder.md` |
| Contacts table + a few cards | Many contacts (communities, classes, events), but only some deserve a full person file | `contacts-table.md` |

Real-world background for all three: `_guide/knowledge/field-notes-2026-10.md`.
